# CitrusScholar experiment toolkit

This directory publishes the reproducible research tooling for CitrusScholar.
It is intentionally separate from the service source and from study data.

- `citrus_scholar_citation60/`: protocols, benchmark definitions, adapters,
  validation scripts and scoring templates for the retained core QA60/EGTS
  experiment and the supplementary 60-question chunk-citation experiment.

The repository does not contain source-corpus text, copyrighted PDFs, local
index files, credentials, raw model responses, human ratings, result tables or
generated figures that require real experiment data.

See `citrus_scholar_citation60/PUBLICATION_SCOPE.md` before attempting to run
the toolkit on another machine.
