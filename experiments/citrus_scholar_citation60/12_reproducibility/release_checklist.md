# 数据发布与复现条款（发表前逐项核对）

- [ ] 所有个人账号、实验室私有SOP、密钥、Cookie、token、私有数据库、未经授权的论文PDF已从发布包排除。
- [ ] 所有题目/Gold/人工评分/运行版本/分析脚本均有SHA清单、许可、来源定位，可在合法条件下复核。
- [ ] 正式题目若引用付费论文，只公开其DOI、页面/图表定位及自行编写的短答案，不完整重发受版权保护原文。
- [ ] 对UCR网站、中文资料、PDF补充数据分别记录许可和抓取时间；不可公开的资料只保存不泄密的内部引用，不放到开放release目录。
- [ ] 用安全凭据管理方式记录实验API访问；输出日志脱敏，避免对话中不小心包含账户或定位信息。
- [ ] 用 `scripts/verify_artifacts.py --manifest ...`验输出文件真实性，下载的实际SHA与登记一致。
- [ ] Git SHA、源索引generation、模型精确ID、prompt、网络时间、程序依赖版本、评分原始文件和CI统计都附实际文件。
- [ ] 评估协议偏离、失败和外部网页不可达要记日志，不能只保留成功样本。
- [ ] 如果用户研究尚未伦理批准/尚无真实参与者，只发布系统案例，不伪造人类参与数据。
- [ ] 最终paper的可复现/数据可得声明准确区分：公开软件、可公开问题、可公开统计、授权受限源数据、不可发布内部资料。
