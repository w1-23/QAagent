# 使用者须知

1. 仓库内实验根目录固定为 `experiments/citrus_scholar_citation60/`；服务器实验根目录由受控运维配置指定，脚本只通过 `CITRUS_EXPERIMENT_L1_ROOT` 读取，不在公开文档写真实 SSH 地址或端口。先阅读 `README_DSH_从这里开始.md`。
2. 当前包含核心 60 问、192 条路由题、24 条复合指令、7 个端到端案例、按实验拆分的脚本入口、题目有效性模板、v4.3.3 执行边界审计、专家评分/仲裁候选实现、判官 candidate 配置、模拟 Excel、统计绘图计划和论文模板。citation60 的冻结题、目标定位和运行计划在 G12 前只保存在服务器 `L1`；审计树只保留安全说明和受控资产清单。
3. 你需要提供：只用于实验的服务器安全访问方式、Agent 与判官分别适用的合法 API 访问、两名回答评分专家和一名分歧仲裁专家，并完成材料许可审核。120 道题的有效性认证仍是独立人工任务，不写 Gold Answer。
4. 所有原始证据都保留，但公开按 `L0/L1/L2` 分级：`L0` 不进入任何包；`L1` 受限全文/SOP/身份映射/原始敏感日志留服务器受控存储；`L2` 通过 release 检查后进入 GitHub。
5. 机器可读的 CSV/JSON 与 SHA 清单是执行时的**机器真值**。不允许用表格显示的空白补 0，也不允许用空白模板冒充已完成的评审或运行。
6. 核心 QA60 由两位专家对全部 180 份回答独立评分、第三位专家仲裁字段分歧，专家共识为主结果；三 LLM 判官是独立自动测量。补充 citation60 只报告 target chunk 确定性命中，不报告 semantic support。
7. 当前计划状态为 `AWAITING_SIXTH_EXTERNAL_GPT_REVIEW`，执行授权为 `NONE`。旧判官脚本禁止执行。本审查提交允许本地静态语法、schema、包完整性、密钥和 Git 检查；凡涉及实验服务、模型/API、数据库、Pilot、正式运行、评分、统计和论文结果的执行，均只在服务器隔离实验实例进行。
