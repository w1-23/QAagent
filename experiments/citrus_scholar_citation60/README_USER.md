# 使用者须知

1. 在**工作区**解压 ZIP，最终只生成根文件夹 `citrusScolarExperiment`。将整个文件夹交给 dsh；先阅读 `README_DSH_从这里开始.md`。
2. 提交的文件包含**全部候选60问、192条意图/路由题、24条复合指令、7个端到端案例（6常规+1综合）、可运行脚本骨架、用于审查的模拟Excel、逐题评分表、统计绘图脚本、论文叙事模板**。不包含尚未实际下载的外部文献全文，也不包含任何伪造的系统评测结果。
3. 你需要提供：真实仓库路径、只用于实验的服务账号/安全访问方式、同模型API的合法访问方式（不要把密钥写进文件或对话）、有权共享的本地语料快照索引；2位领域评审的Gold；完成材料许可审核。
4. 原始记录和论文数据均存此目录，不污染服务器代码/账号数据，不擅自修改生产服务。
5. `实验管理台账.xlsx`是早期表格模板，脚本的规范化 CSV/JSON 为执行时的**机器真值**。不允许用Excel显示的空白补0。
