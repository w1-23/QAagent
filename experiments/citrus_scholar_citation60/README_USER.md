# 使用者须知

1. 在**工作区**解压 ZIP，最终只生成根文件夹 `citrusScolarExperiment`。将整个文件夹交给 dsh；先阅读 `README_DSH_从这里开始.md`。
2. 提交的文件包含**核心 60 问、补充 60 个冻结题及完整冻结 chunk 正文、192 条意图/路由题、24 条复合指令、7 个端到端案例、按实验拆分的脚本入口、题目有效性模板、专家评分材料模板、判官材料、模拟 Excel、统计绘图脚本和论文叙事模板**。真实运行、专家原始评分、仲裁、判官响应和分析产物按版本回写；密钥和未获授权公开的源材料不入库。
3. 你需要提供：只用于实验的服务器安全访问方式、Agent 与判官分别适用的合法 API 访问、两名回答评分专家和一名分歧仲裁专家，并完成材料许可审核。120 道题的有效性认证仍是独立人工任务，不写 Gold Answer。
4. 原始记录和论文数据均存此目录并纳入版本控制，不污染服务器代码/账号数据，不擅自修改生产服务。
5. 机器可读的 CSV/JSON 与 SHA 清单是执行时的**机器真值**。不允许用表格显示的空白补 0，也不允许用空白模板冒充已完成的评审或运行。
6. 核心 QA60 由两位专家对全部 180 份回答独立评分、第三位专家仲裁字段分歧，专家共识为主结果；三 LLM 判官是独立自动测量。补充 citation60 只报告 target chunk 确定性命中，不报告 semantic support。
7. 当前计划状态为 `AWAITING_EXTERNAL_GPT_REVIEW`。所有实验、模型调用、测试、数据库检查和分析只在服务器隔离实验实例运行；本地不得执行。
