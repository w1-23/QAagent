# 使用者须知

版本：`4.4.0`
当前状态：`AWAITING_EXTERNAL_GPT_REVIEW_V4_4`

1. 实验验证的是完整 CitrusScholar，而不是一个禁止 Agent 访问语料的演示
   系统。题目可以发送给 Agent，Agent 可以通过平台正常检索和阅读完整语料。
2. 完整语料不复制到 GitHub。GitHub 保存协议、代码、来源登记、索引
   generation、SHA、脱敏运行证据、评分、统计和论文材料。
3. `L1` 只是服务器留存与发布分级；`CITRUS_EXPERIMENT_L1_ROOT` 不是 Agent
   测试前置条件。
4. 每个独立问题使用一个新会话；不同条件、重复运行分别建会话；相关长工作流
   使用一个独立会话完成连续任务。
5. 每位专家会收到盲化问题、回答、引用、冻结参考证据、评分说明、可填写评分表
   和完成检查清单；专家看不到条件、模型、运行 ID 或另一名专家的分数。
6. 核心 QA60 由两位专家对全部 Pilot 36 和正式 180 份回答独立评分，第三专家
   仲裁四维字段分歧；LLM 判官是独立自动测量。
7. 本轮只提交准备修订，等待 GPT 审查确认。审查通过后才在服务器执行真实
   Agent/Judge 调用，不会用本地结果、模拟结果或硬编码回答代替。
8. 聊天中暴露过的旧 API Key 已视为失效，不得复用。密钥只配置在服务器受保护
   环境文件中，不进入 GitHub 或实验证据。
