# 使用者须知

1. 在**工作区**解压 ZIP，最终只生成根文件夹 `citrusScolarExperiment`。将整个文件夹交给 dsh；先阅读 `README_DSH_从这里开始.md`。
2. 提交的文件包含**核心 60 问、补充 60 个冻结题及目标元数据、192 条意图/路由题、24 条复合指令、7 个端到端案例（6 常规 + 1 综合）、按实验拆分的脚本入口、240 条题目有效性模板、180 条 LLM 判官模板、用于审查的模拟 Excel、统计绘图脚本和论文叙事模板**。不包含外部文献全文、受限 chunk 正文、原始判官响应、真实评分或任何伪造结果。
3. 你需要提供：真实仓库路径、只用于实验的服务账号/安全访问方式、同模型 API 的合法访问方式（不要把密钥写进文件或对话）、有权访问的语料来源；两名研究生/领域评审只认证 120 道题的有效性，不写 Gold Answer；完成材料许可审核。
4. 原始记录和论文数据均存此目录，不污染服务器代码/账号数据，不擅自修改生产服务。
5. 机器可读的 CSV/JSON 与 SHA 清单是执行时的**机器真值**。不允许用表格显示的空白补 0，也不允许用空白模板冒充已完成的评审或运行。
6. 核心问答由两套冻结 LLM 判官评分，分歧由预冻结 LLM 仲裁者处理；补充 citation60 只报告 target chunk 确定性命中，不报告 semantic support。
