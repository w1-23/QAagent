# Manuscript workspace

This directory contains the complete manuscript planning, traceability and
versioning assets. It currently contains no experimental results.

Files:

- `storyline_and_writing_plan.md`: paper argument, related work and narrative.
- `manuscript_skeleton.md`: editable section skeleton with explicit placeholders.
- `abstract_template_NO_RESULTS.md`: abstract template that cannot be submitted
  until real results replace every bracketed field.
- `claim_source_map_TEMPLATE.csv`: required claim-to-evidence ledger.
- `table_figure_provenance_TEMPLATE.csv`: table/figure lineage plan.
- `paper_version_registry.csv`: paper version and data-freeze history.
- `review_response_log.csv`: reviewer comments and response tracking.
- `reviewer_objections_and_responses.md`: anticipated objections.
- `related_work_source_links.csv`: related-work source register.

The operational writing plan is `../00_protocol/05_论文写作执行计划.md`.
