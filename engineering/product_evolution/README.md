# CitrusSchalor 本地修复与验收

开发目录：`E:/codex_WORKSPACES/CitrusQA_Local`。显示品牌为 **CitrusSchalor**，GitHub 仓库名及内部资源路径不随显示名称更改。

本目录保存当前开发分支的独立工程验证入口与结果。全部材料是明确标识的合成工程夹具，不是用户科研数据，也不构成科研结论。历史测试、基准、评分器和外部实验 harness 不在执行范围内。

## 当前实现边界

- 聊天中的工作台入口位于资料库下方；移除输入区绘图开关，保留自然语言绘图能力。
- 图件以数据/spec、语义对象清单、样式差异及服务端不可变版本为真源；画板缩放、平移、网格和标尺属于浏览视图，不改变源数据或正式导出。
- 拖动结束和属性修改触发临时预览，单请求运行并合并后续修改；预览不写文件、版本或引用。保存使用 expected_revision，成功后才发布。按用户要求，每图只保留最近一次正式保存；旧项目引用解除后按已有文件 GC 策略清理，不删除其他消费者引用。客户端撤销/重做只作用于未保存编辑。
- 图内对象按文字、数据系列、图例、坐标轴分组；系列下有单点/单柱，轴下有刻度子组。组编辑只开放共有样式，一次撤销还原整组。文字支持内容、位置、字体/字重/斜体/对齐/字号/颜色；散点支持形状、大小、填充、描边与透明度；系列名称和样式同步对应图例，图例支持位置和列数。实际能力由manifest声明；数据点位置、柱高、误差长度及数值刻度内容不是样式属性。移除对象用可撤销visible记录。
- 使用指南为聊天页与工作台共用的12页原地弹窗，每页带原创操作图示；不通过链接跳转离开当前工作。图形属性复用Matplotlib现有API，模态层复用原生dialog，来源与许可记录在 `EDITOR_REUSE.md`。
- 自包含脚本在隔离 worker 内重放编辑并回传完整对象清单和规范化修改，不向 Web 进程传 Figure。缺少安全 runner 或历史输入映射时拒绝；不将开发 LocalBackend 测试当作实际 Docker 验收。
- 账号注销使用单进程准入与工作租约。取消等待不等于同步线程结束；实际线程和指定持久化操作结束前不清除账号。该机制尚不能用于多 worker 部署。
- HTTP 按账号和 client_request_id 登记持久任务，同键同内容返回原任务事实，不重复执行；同键不同内容返回冲突。这不是进程重启后的计算检查点续跑。
- 跨文件数值复核提供双源哈希、原表行列/单元格定位、检测范围和合法转换等反例。整数汇总一致性以报告小数精度推导区间，不把无法检查写成通过。
- 图像复核仅覆盖受限的精确像素对应、90°旋转/镜像与采样裁剪匹配。命中必须人工复核；未命中不证明没有复用；不支持缩放、任意旋转、JPEG重新压缩或颜色处理后的近似匹配。

## 离线回归

在仓库根目录使用现有开发环境执行：

```bash
E:/anaconda/python.exe -B -X utf8 engineering/product_evolution/run_checks.py
```

指定一组：

```bash
E:/anaconda/python.exe -B -X utf8 engineering/product_evolution/run_checks.py --group contracts
```

入口明确列出测试文件，不进行任意测试发现。每次运行创建新的 `results/<UTC时间>-<随机后缀>/`，保存日志、JUnit XML 和 summary.json，不覆盖历史结果。Python 子进程使用临时状态目录，阻断真实模型、检索和外部网络，保留 Windows asyncio 所需的本地回环连接。Node 测试运行生产 JavaScript 的行为。

应区分：测试夹具/模拟后端通过、真实浏览器操作通过、真实 Docker 执行通过。一个层次不能替代另一个层次。环境无法创建符号链接时对应测试跳过，应保留原因。

## 浏览器验收实例

`.claude/launch.json` 中的 `figure-semantic-final` 启动实际 FastAPI 应用，监听本地8135，覆盖内容/形状/分组新增能力和最新SVG样式修复。`figure-object-acceptance` 为8134旧实例，`figure-editor-final` 为8133实例；较早的两个配置使用8132与8131。8131、8132和8134停止操作曾被自动审批拒绝，未绕过拒绝终止进程。最终图件验收以8135为准。`preview_app.py` 创建临时账号、会话，并由 `acceptance_figures.py` 发布三组×八时间点×三重复的合成趋势、散点和柱形图。真实使用身份验证、CSRF、项目路由和发布流程，停止即丢弃该实例状态。

`editor_acceptance.py --port 8135` 通过独立临时 Chrome / CDP 原生鼠标拖动验证实际页面，截图和检查记录保存到新结果目录。`browser_driver.py` 只启动自有临时浏览器，不连接用户日常浏览器。

该入口关闭生产 lifespan，阻断真实模型、RAG 和外部网络。因此它可以验证页面和绘图工作台，不证明生产启动预热或自然语言模型选择工具的整条链路已验收。

浏览器验收包括：

- 主导航顺序、品牌、输入控件及背景/主题保持。
- 打开丰富合成图、实际拖动文字、修改字体、单点颜色及轴线、删除/撤销恢复、动作后预览、保存与最近结果下载。
- 缩放、适应窗口、平移、网格/标尺、窄屏和键盘操作。
- 同一正式版本的预览与 SVG 下载字节一致，PNG/PDF 可下载。
- 换账号后看不到前一个账号的图件，旧请求不能回写当前界面。

首批记录保留在 `ACCEPTANCE.md`；本轮图件与分页指南的最终运行证据及边界在 `FIGURE_EDITOR_ACCEPTANCE.md`。`guide_acceptance.py` 额外验证聊天页内12页指南、图示、窄屏及焦点恢复。只有存在真实结果的检查才能标记完成。
