# 图件对象编辑：独立行为规格

2026-11-13。输入是用户提供的产品截图、公开技术说明与公开试用的可见界面。此文只定义 CitrusSchalor 要达到的用户行为，不包含第三方源码、内部算法移植或视觉资产复制。开发分工按这份功能描述和本地既有代码实现；这里的“独立”不构成法律上的洁净室认证，也不是性能或格式兼容承诺。

## 本轮交付行为

| 用户动作 | 应看到的结果 | 验证依据 |
|---|---|---|
| 展开图内对象 | 文字、数据系列、图例、坐标轴分组；点/柱在所属系列下，刻度在所属轴下 | 实际对象树与可见控件 |
| 选择类别后改共有样式 | 整组适用对象变化，一次撤销还原整组 | overrides集合、实际渲染、撤销后输出 |
| 修改标题、轴标题、注释内容 | 内容立即进入未保存预览；保存/重开保留 | 实际SVG文字和重新加载后的manifest |
| 修改系列名称 | 对象列表和对应图例同步，稳定对象身份不变 | 图例文字、gid和保存后的重放 |
| 改散点形状/大小/填充/描边/透明度 | 图内散点变化，整组系列的图例标记同步；单点变化只覆盖该点 | Artist路径/样式、实际SVG，坐标保持 |
| 改曲线颜色/线型/标记 | 曲线及其图例同步；误差棒组件不得保留旧颜色 | 实际SVG和图例Artist |
| 移动文字 | 位置与文字内容、字体修改可以组合，动作结束重绘 | 原生鼠标操作、预览图像变化 |
| 移除对象并撤销 | 对象从画面消失但仍可在列表恢复 | 真实输出、可见性、撤销 |
| 打开使用指南 | 当前页内分页弹窗，完整说明和图示按当前功能组织 | URL不变，页面切换、关闭返回原编辑状态 |
| 保存 | 当前预览提交成最近一次正式保存，仅留一个项目保存快照 | revision/CAS、版本数量、预览和下载字节 |

## 实现契约

- 源数据与spec/script独立保存，编辑以稳定gid指向白名单属性。未保存预览不创建产物或项目历史版本。
- 文字内容字段是有长度上限的文字；输入不会作为HTML、Python或外部TeX执行。数值刻度内容不开放任意改写。
- 批量样式只取组选中对象的能力交集；不把同一个标题文本或系列名称复制到全组。
- 数据点/柱子的展示属性可以变，数据坐标、柱高和误差长度不属于样式编辑。
- 图例绑定必须可确定。无法确定来源关联时拒绝需要同步的修改，不把“只改了图内、没改图例”报为成功。
- 保留现有背景、主题、账号隔离、请求代次、保存冲突与安全执行边界。

## 本轮边界

左栏选择是完整编辑入口；鼠标bbox选择作为便捷操作，不承诺曲线距离拾取。拖动中当前只移动选择框，释放后实际图像重绘。未纳入多面板拼版、任意Artist、画布尺寸/坐标范围编辑、完整期刊规范核验或第三方产品的全部功能。
