# Tavotto 公开行为对照与独立实现

核查日期：2026-11-13。仅观察公开技术说明、试用界面与用户提供的操作截图；未读取、复制或移植其实现源码。当前公开技术页末尾自述“基于 AGPL-3.0 协议开源”，但本轮不据此推定全部发行物的许可，也不以许可作为复用依据。以下不是等价兼容声明，也不是性能比较。功能观察先整理为 `EDITOR_BEHAVIOR_SPEC.md`，实现仅基于该规格及 CitrusSchalor 既有代码。

## 观察依据

- [技术说明](https://www.tavotto.com/zh/technology/)：源脚本与编辑差异分离、Matplotlib Artist 语义身份、前端拾取、拖动与后端重绘、请求代次和渲染版本。
- [产品公开功能](https://www.tavotto.com/zh/)：文字/轴/曲线/图例独立选择、毫米排版、规范核验、矢量与位图交付。公开介绍中的性能与格式承诺不能套用到本项目。
- [公开试用](https://www.tavotto.com/try/?lang=zh)：真实独立 Chrome 打开并选择动力学示例；成功加载后的界面包含按文字、数据系列、图例、坐标轴分组的对象栏，画布标尺，图幅 W/H、背景色、透明背景和源文件入口。初始示例选择页还展示校准曲线与光谱。部分重试受 Pyodide/CDN 加载耗时影响，没有可靠取得每一种属性面板的完整行为。
- 实际界面观察记录：`results/20261113T151710Z-reference-ui/public-ui.json` 与同目录截图；补充 `results/20261113T155537Z-reference-ui/` 和 `results/20261113T160310Z-reference-ui/`。补充运行成功打开示例和关闭引导，但脚本点击未可靠切换属性面板，因此不将这些记录称为文字、散点或图例编辑的亲自验收。
- 用户提供的实际操作截图明确展示：文字内容输入、散点形状/大小/填充/描边/透明度、曲线线型、图例列数与位置，以及类别组和子对象结构。这些是本轮行为规格的依据，不能反推其内部源码。

## 对照

| 原理或功能 | CitrusSchalor 的实现 | 范围 |
|---|---|---|
| 保留源脚本与数据，编辑单独存储 | spec/script + overrides；样式不覆盖数据 | 数据和方法变化仍需重新生成来源 |
| 语义对象清单 | 稳定 gid、locator、角色、bbox、属性白名单 | 支持的文字、曲线、轴线、单点、单柱；不是任意 Artist 全覆盖 |
| 精确选择 | 小对象在大对象之上，根画布不截获鼠标；列表分类与搜索 | 使用 bbox，未实现沿曲线距离拾取 |
| 文字移动 | Pointer capture、缩放坐标换算、键盘移动 | 数据点坐标不作为样式移动 |
| 动作后重绘 | 单请求运行，合并后续修改，丢弃过时响应；临时 SVG 仅作为 img | 拖动中移动选择框，松手后真实图像重绘 |
| 文字内容与样式 | 标题/轴标题/注释文字，实际安装字体、字重、斜体、对齐、字号、颜色 | 普通文字输入，不执行HTML或外部TeX；不改数值刻度内容 |
| 散点与曲线 | 复用Matplotlib标记路径、大小、填充/描边、透明度、曲线线型 | 整组及单点能力按manifest声明，不移动观测坐标 |
| 图例同步 | 系列名称及标记样式同步到对应图例；图例位置、列数、文字样式 | 关联不明确时拒绝相应同步修改；独立注释不自动当作系列名称 |
| 对象组织 | 类别组可折叠，系列下放单点/单柱，轴下放刻度；组共有样式批量编辑 | 左侧列表是可靠入口，不以精准鼠标拾取为前提 |
| 删除与恢复 | visible 编辑，可撤销；保留原始来源 | 删除数据标记只改变显示，交付需解释筛选依据 |
| 脚本编辑 | 隔离 worker 内捕获对象、应用白名单、导出 | 自包含脚本；未保留输入映射的历史脚本拒绝重放；无 runner 不执行 |
| 保存 | CAS 发布，当前预览 + 最近一次正式保存 | 按用户要求取消历史版本串；旧产物解绑后进入已有 GC，不误删共享文件 |
| 物理视图 | mm 尺寸显示、标尺、网格、缩放、平移 | 画布尺寸只读，尚无多子图拼版编辑 |
| 投稿与导出 | 模型按 figure contract/nature-figure 工作流出图；统一 Figure 状态导出 | 尚无完整期刊 profile 自动核验；PDF/PNG/SVG 不是同一 PDF 内核派生 |

## 独立实现约束

界面只向用户提供实际对象声明的属性。预览不发布文件或创建保存记录；只有保存成功后下载才代表新结果。SVG 不作为活跃 DOM 插入页面。隔离脚本的对象清单及已应用修改通过有界 JSON 文件回传，宿主不执行脚本或反序列化 Figure。

后续能力边界按本地验收记录报告，不以“已逆向”代替真实操作与输出验证。
