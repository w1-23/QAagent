## 结论与适用边界

审核包暴露的多项路由、参数调用、重复产物和状态矛盾具有明确的工程根因：来源约束解析不一致、附件存在被误当作禁止检索、提示词给错工具入口、工具参数绕过预检、交付前后的缺口记录未刷新，以及范围上限与真实未完成混为一谈。本轮已针对这些根因修改源码、同步系统提示词，并补上离线回归。

当前源码通过 **422 项离线检查，0 失败、0 错误、0 跳过**。这说明指定工程契约在这些测试中成立，不能推出真实端到端科研任务全部成功，也不能换算成新的 FW 或路由得分。第三方服务超时、科学判断质量、证据不足和评分器的能力映射口径仍须分别理解。

本轮没有启动、停止或重启运行服务，没有调用真实服务端任务，没有运行 Case A/B/C，没有重跑 FW20/40 或 240 题路由实验，没有修改外部 harness、gold、评分器、历史实验结果和原始审计材料。本轮修复尚未提交或推送。源码和磁盘提示词已更新，**运行进程采用新代码仍需之后受控重启；本轮未验证其内存版本**。

## 根因、改动与行为变化

| 工程问题 | 根因与修复 | 现在的边界 |
| --- | --- | --- |
| 结论、清单、可追溯要求被额外算成文件 | 交付解析采用显式载体优先；保留完整子句辨认“标注”类型；仅合并同一产物的重述 | 真正独立的两份产物仍保留身份，需求与产物的二分匹配规则未放宽 |
| 两份报告导致整组无法导出 | 按需求逐个判定正文归属；第一份可使用本轮回答，独立简报缺正文则明确记为未执行 | 不把完整内部报告复制成脱敏对外简报；不伪造第二份正文 |
| 相同内容反复生成新版本 | OOXML 的 ZIP 时间戳与 core.xml 创建/修改时间统一规范化，再计算发布哈希 | 相同请求的相同产物可复用；新内容仍产生不可变新版本，旧下载字节不变 |
| 文件回执哈希与下载文件不一致 | Word finalize 使用发布端实际哈希；两条审查路径在回执计算前统一规范化字节 | 回归比较实际发布文件、索引与工具回执的 SHA-256 和字节数 |
| 宽表永远 partial、成功审查被归为内部错误 | `scope_limited` 与 `coverage_incomplete` 分开；补齐结果原因映射 | 已完成声明范围不代表全表全规则均扫描；真截断、跳过、失败和人工漏行仍为 partial |
| 人工标注一个坏条目中止整批 | 逐条校验、收集拒绝原因、保留有效条目；全无效时拒绝，不能自动改成规则扫描 | 结果文字与工作簿概览均保留未采用条目，不能说整批完成 |
| 工作表不存在或漏写被静默忽略 | 明确列出可用表名；多表不猜；未知表名进入 skipped 和覆盖记录 | 不会把无法定位的标注强行写进另一张表 |
| 标注后“正常”变成红色待核查 | 共用工作簿写入器保留人工 level，区分正常、需核查和错误，批注明确是模型意见 | 不改变原单元格值、公式或合并关系，不把模型意见变成确定性结论 |
| 覆盖行数偏差 | Excel 源行数扣除表头；处理行数按真正交付给审查器的 DataFrame 计算 | 只标完可见截断片段不会被报成完整覆盖；缺口包括未解析的源行 |
| 参数错误无法自纠 | 常规派发与 DSML 恢复复用 schema 预检；补充合法参数、期望元素形状、收到的类型和可选文件 | `deepseek_fetch(doi=...)` 被派发前拒绝并指向 `deepseek_fetch_paper` |
| 超时提示跳过未读内容 | 统一请求时限来源；超时后重试尚未确认完成的同一窗口或分页 | 只有成功回执才授权前移；未重新引入 60/180 秒的暗上限 |
| 空回答没有终态、停止被写成失败 | 空回答仍发送 done；按真实流水推导终态；停止分支同步 job 和审计状态 | 空回答不编造正文，失败保持失败；用户停止保持 cancelled |
| DSML 协议残留导致空收尾 | 最终合成复用有界恢复，移除无用分支 | 恢复次数有上限；不能把协议文本当最终答案 |
| 已交付链接旁仍写“未生成” | 在部分交付时也对齐交付文字；门补导后重新计算机器缺口和提示计数 | 只修正文件否认句，保留未核验、未扫描和特定文件尚未交付等事实 |
| 工具气泡显示“科研工具” | 工具标签与真实声明表一一覆盖，补全产物链接标签 | 未知工具仍有兜底，但当前声明工具不能依靠兜底冒充覆盖 |
| 大结果提示不存在的读取工具 | registry 不再提前丢弃结果；先保留证据，再压缩模型视图 | 模型视图上限 40,000 字符；证据保留上限 200,000 字符，并记录原始长度、全量哈希与截断信息，不声称无限全文留存 |
| 本地限定落成 auto | 来源约束由共享 `source_scope` 解析，补充“在库内”“当前索引”等表达 | 禁止联网不顺带禁止所要求的本地检索；无条件“不要检索”仍生效 |
| 上传 PDF 导致检索工具消失 | 只有明确“只读附件／不要检索”才启用该限制，上传本身不移除工具 | 保留必要出版记录核验能力；有工具不等于已调用，最终仍以执行回执为准 |
| 跨句出版记录核验漏判 | 限定相邻子句／相邻句的显式回指，识别“这 15 篇”等核验对象 | 不让前文文献语境无限传递给不相关的表格检查；保留否定判定 |
