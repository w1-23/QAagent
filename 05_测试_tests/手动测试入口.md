# CitrusQA 手动测试入口

这是给人直接打开 CitrusQA、逐题提问并按题目上传附件的验收包入口。不是 pytest 脚本目录。

## 打开测试包

测试包根目录：
E:\codex_WORKSPACES\Citrus_QA_Agent\01_源码_src\test_delivery\CitrusQA_连续人工测试_20261025

先读根目录的 README_从这里开始.md，按编号进入功能文件夹；每组新建会话，并只上传题目明确指定的附件。测试者核对说明只供验收者查看，不要发给 CitrusQA。

## 按功能选择题目与附件

| 编号 | 场景 | 题目文件 | 配套附件 |
| --- | --- | --- | --- |
| 01 | 基础问答与连续会话 | 01_基础问答与连续会话/测试问题.md | 无 |
| 02 | 本地检索与联网检索 | 02_本地与联网检索/测试问题.md | 无 |
| 03 | 论文解析与参考文献核验 | 03_论文解析与参考文献/测试问题.md | 合成论文及引用.pdf、合成论文及引用.docx、合成多工作表数据.xlsx |
| 04 | 统一科研数据审查 | 04_统一数据审查/测试问题.md | 合成_复杂数值模式.csv、合成异常数据.csv、合成_行向与局部复用.csv、合成_跨文件错位关系.csv、合成_正常对照与单位换算.csv |
| 05 | 可视化与科研导出 | 05_可视化与科研导出/测试问题.md | 默认无；需要验证视觉输入时用合成图像输入.png |
| 06 | 异常与未完成边界 | 06_异常边界/测试问题.md | 空表.csv、损坏文件_请勿解压.xlsx |

各题具体上传时机和操作顺序以对应目录中的测试问题.md 为准。04 目录另有合成多工作表数据.xlsx，可用于缺失、混合类型、重复、极端值与组别失衡等覆盖。
