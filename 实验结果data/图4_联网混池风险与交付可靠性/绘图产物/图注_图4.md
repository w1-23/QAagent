## 英文图注（可直接入稿）

**Fig. 4. Web-source mixing risk in the previous architecture and structural verification of source separation in the deployed system.**

**(a)** Judge-flagged hallucination rate under five evidence-handling conditions in the **previous mixed-arbitration architecture** (experiment run 23–24 September 2026, before source separation was implemented): a local-only control (A), unfiltered mixing of web content into the local evidence pool (B), receipt-level filtering (C), model-visible filtering (C′), and excerpt-only filtering (D). The left column shows the absolute rate (%), the right column the difference relative to the local-only control in percentage points; the rightmost column gives the number of flagged events and valid verdicts. Each condition was tested on the same 48-question subset with two independent LLM judges, yielding 96 verdicts per condition. Differences are descriptive; no significance testing or confidence intervals are shown. Because the judges could inspect only a 300-character preview of each cited source, this rate is a judge-flagged measure rather than a confirmed fabrication rate.

**(b)** Structural verification of **source separation in the deployed system** (v11 run, 26 September 2026), presented as two audit groups with **different statistical units**. *Source-boundary compliance* (answer- and occurrence-level; 144 three-pool answers): in-text web markers `[Wn]` never appeared inside a local-answer section (0 of 144 answers), and all 820 web markers occurred inside the separate web section. All 48 Pool C answers satisfied the predefined segmentation rule (48/48): each carries a separate web section and none places a web marker in its local section. Within that row, 47 of the 48 answers actually used a numbered web citation; the remaining answer (C48-new-33) corrected a false premise in the question and therefore carries no numbered citation — this is not a segregation failure. That row is drawn as a **unit chart**, one dot per answer, with the unfilled dot marking C48-new-33. *Citation integrity* (marker-level; 84-question system-layer evaluation): all 1,649 in-text citation markers were resolvable to a source inside the retrieved evidence pool and none were out-of-pool. Citation resolvability is a structural property — it shows that a marker can be linked to an existing source, and does not establish that the source semantically supports the corresponding claim. The two groups use different units of analysis and must not be combined into a single compliance score; "used a web citation" (47/48) and "met the segmentation rule" (48/48) are likewise different criteria.

## 中文图注（供内部核对／中文稿）

**图 4｜旧架构的联网混入风险，以及已部署系统来源分离的结构核验。**

**（a）** **旧混合仲裁架构**（实验运行于 2026-09-23/24，早于来源分离实现）在五种证据处置条件下的
judge-flagged 虚构率：仅本地对照（A）、联网内容未过滤混入本地证据池（B）、回执级过滤（C）、
模型可见级过滤（C′）、仅摘要过滤（D）。左列为绝对率（%），右列为相对仅本地对照的百分点差；
最右列给出被标记事件数与有效判定数。五种条件使用同一 48 题子集、两位独立评审模型，
每条条件 96 条判定。差值为描述性比较，不作显著性检验、不绘制置信区间。
由于评审只能查看每条被引来源的 300 字预览，本指标是**判官标记率**，不等同于已确认的编造发生率。

**（b）** **已部署系统来源分离的结构核验**（v11 运行，2026-09-26），以**两套统计单位**分两组呈现。
*来源边界合规*（回答级与次数级；三池 144 条回答）：正文联网标记 `[Wn]` 从未出现在本地答案段内
（144 条回答中 0 条），820 个联网标记全部位于独立联网段内。库外强时效池的**全部 48 条回答均满足
预定义的分段引用规则（48/48）**——每条都有独立联网段，且本地段均不含联网编号。
该行之内，48 条中有 47 条实际使用了带编号的联网引用；剩余 1 条（C48-new-33）改正了题目中的错误前提，
因而未附联网编号，**不属隔离失败**。该行以**单位图**呈现：一个圆点代表一条回答，末位空心点即该题。
*引用完整性*（标记级；系统层 84 题评批）：1,649 个正文引用标记全部可解析到检索证据池内的来源，
池外引用为 0。引用可解析性是**结构性**属性——它说明标记能指向一个真实存在的来源，
并不证明该来源在语义上支撑相应论断。两组统计单位不同，**不得合并为单一合规率**；
同样，「是否使用联网引用」（47/48）与「是否满足分段规则」（48/48）也是两个不同判据。

## 禁止的表述（审稿风险）

1. ❌「来源隔离使被标记虚构率从 24.0% 降到 3.1%」——（a）与（b）**不是同一次前后对照实验**；
   （a）是旧架构观察，（b）是新架构结构核验。
2. ❌「（b）证明架构有效降低了幻觉率」——（b）只验证**预先定义的分段引用规则**得到执行，
   不测量语义质量、也不是时效事实正确率。
3. ❌「所有过滤方案都无法改善到不联网水平」——该结论在判官口径下成立，
   但确定性引用支持度口径下 D vs A 不显著（+0.004），两口径必须并列申报。
4. ❌ 把（a）的 A 组说成"零风险组"——不联网条件下仍出现 3/96 标记（`C48-new-02` 可判为真编造，
   `C48-time-011` 需核对完整 chunk 后定性）。
