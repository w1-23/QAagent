## 四、回滚方法（代码回滚 ≠ 数据库恢复）

代码回滚（不动任何数据库）：

```bash
cd /home/WZQ/CitrusQA
tar czf backups/source-before-rollback-$(date +%Y%m%d-%H%M%S).tar.gz 01_源码_src/src 01_源码_src/web
# 恢复部署前备份（部署时生成）
tar xzf backups/source-before-54bf15c-20261030-173502.tar.gz -C .
PID=$(ss -ltnp | grep ':8000 ' | grep -o 'pid=[0-9]*' | head -1 | cut -d= -f2)
kill "$PID"; sleep 3
cd 01_源码_src && setsid nohup ../.venv/bin/python -m uvicorn src.api.main:app \
  --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1 --workers 1 \
  > ../logs/prod_8000_$(date +%Y%m%d_%H%M%S).log 2>&1 < /dev/null & disown
```

数据库灾难恢复是**另一件事**，只在确认数据损坏时执行，且必须先把当前库另存：

```bash
cp agent/state/sessions.db agent/state/sessions.db.before-restore-$(date +%s)
```

禁止用旧库覆盖新库来完成「代码回滚」——那会丢掉部署后产生的全部会话。
