## 5. 遗留风险与待决

1. **生产未部署**：`54bf15c` 之后 20+ 提交只在本地与 staging。部署需你确认，且应按「`b2fd9ae` 长度保护 → `f83c369` 竞争策略」分批。
2. **未 push**：`qaagent` 远端仍为 `54bf15c`。
3. **staging 标签陈旧**：`DEPLOYED_COMMIT` 写 `e3fc7c7`，实际源码已是竞争实现；建议部署脚本改为写入 `git rev-parse`。
4. **体感项无法自动验收**：长按选刻度、拖拽跟手度、微动作频率（单帧约 400 ms，5 s 采样会漏）。
5. **"删除单条提问"没有 API**：只有整会话删除；导航的"跟随数据变化"是用 DB 删除证明的，不是端到端功能。
6. **`/context-detail`、`/turn-context` 鉴权粒度**：目前按会话归属校验，尚无独立审计日志。
7. **`/context-detail` 旧会话无快照**：快照从本功能上线后开始，历史轮次不回补（已在 UI 明确写出）。
8. **吉祥物素材是 CSS sprite**：无真补间，极限缩放（>4K）需重新出图。
9. **批量验收依赖本机 CDP**：`cdp_shot.js` 需 Chrome 路径与登录 cookie，换机器要重建。

## 6. 部署与回滚

### 6.1 部署（生产 8000）
```bash
# 服务器
cd /home/WZQ/CitrusQA
tar czf backups/source-before-<commit>-$(date +%Y%m%d-%H%M%S).tar.gz 01_源码_src/src 01_源码_src/web
# 上传 git archive（必须关 autocrlf，否则 CRLF 会污染 sha）
git -c core.autocrlf=false archive --format=tar.gz -o /tmp/cand.tar.gz <commit> 01_源码_src/src 01_源码_src/web
# 解包 → 清 __pycache__ → 重启（本仓 uv 无常驻服务，手工 setsid 启动）
kill <pid>; sleep 3
cd 01_源码_src && setsid nohup ../.venv/bin/python -m uvicorn src.api.main:app \
  --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1 --workers 1 \
  > ../uvicorn-8000.log 2>&1 < /dev/null & disown
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/
```

### 6.2 回滚
- 代码：解包 `backups/source-before-*.tar.gz` 覆盖 `src`+`web` → 重启（**不需要**动数据库）
- 数据库：`messages.execution_json` 为 ALTER 兼容列，旧代码忽略即可；如需回退数据，用 `backups/sessions-before-*.db`
- **纪律**：代码回滚 ≠ 数据库回滚。先回代码，数据只在确认损坏时回滚。
