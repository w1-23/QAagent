4. `请把刚才的核验结果整理成一份可下载的小表，方便我复制到组会材料里。登记库没查到时请写“未查到/未核实”，不要写“文献不存在”。`

## 测试者核对说明（不要发给模型）

- PDF 和 DOCX 是同一份合成短稿，内容不足以支持论文之外的推断；重点看模型是否如实指出缺少的结果或统计细节。
- 第 2 题用 CitrusQA 自身的 Web Search/Fetch 查询用户给出的来源，不连接或调用 Claude 模型；Claude Skills 仓库页面仅作为抽取流程参考。核对 arXiv 链接的实际题名后再归纳其研究结论。
- 当前短稿主要验证基本文本/表格抽取差异，不包含多栏伪表格和跨行连字符的专门压力样例；模型不得声称已实测这些失败模式。
- `10.1534/genetics.114.163105` 是真实 DOI；`10.5555/citrusqa-e2e-fake-2026` 是负例占位 DOI。
- DOI 查询失败或登记库无记录不能证明文献不存在；书目信息匹配也不等于该文献支持短稿中的具体结论。
- 本组测试附件解析、联网元数据核验与导出，不要求自动高亮 PDF 引文或绕过付费访问。
