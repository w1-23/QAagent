# 连续对话：准备柑橘课题组汇报材料

新建会话。第 1 题前打开网页的“可视化输出”开关。第 5 题上传 `叶片观察示意图.png`。

## 对话

1. `我要给课题组新同学解释一份补充数据从“原始表格”到“规则筛查”，再回到“原始记录人工复核”的过程。请画一张简洁的中文流程图，适合放进汇报页，保留可编辑 SVG 下载。`
2. `这张图里的每一步分别解决什么问题？请用几句话解释，并告诉我页面显示的是图，还是只有一段 SVG 代码。`
3. `我还需要做一个柑橘幼苗耐盐预实验。请给一个可讨论的设计：盐浓度梯度和对照、每组重复、0/7/14/28 天的采样安排、叶片相对含水量/SPAD/MDA/生长量指标，以及最需要控制的混杂因素。哪些是建议、哪些需要文献或预实验确认，请分清。`
4. `把刚才的耐盐预实验方案整理成一个可编辑、方便我改的文件，文件名根据“柑橘幼苗耐盐预实验”自动生成；如果能把前面的流程图作为 SVG 资源一并放入报告，也请一起提供。`
5. **上传 `叶片观察示意图.png`：** `我准备把这张叶片记录示意图放在新生培训材料里。请只描述图里能直接看到的叶片形状、斑点和标线，并告诉我它适不适合作为病害诊断的真实病例图；它是示意图，不要给病害诊断。`

## 测试者观察

- 第 1 题要得到渲染后的 SVG 预览和下载，不应只把源码当普通文本。
- 第 2 题检查可视预览和文件内容是否一致。
- 第 3、4 题检查实验方案是否含设计要素、是否明确建议性质、文件是否可编辑且按主题命名；若 SVG 不能嵌入该文件格式，应如实说明并提供独立 SVG。
- 第 5 题检查主模型是否确实读取图片并遵守“描述示意图、不诊断”的要求。
- 关闭可视化开关后，另开一个简单问答会话；应不再额外调用绘图工具。
