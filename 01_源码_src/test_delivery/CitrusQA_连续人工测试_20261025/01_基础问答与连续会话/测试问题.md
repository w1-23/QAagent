# 连续对话：接手柑橘课题时怎么开始

新建会话，按顺序提问。第 3 题附上 `04_统一数据审查\田间调查_多批次记录.csv`，但本轮先不要求分析它。

## 对话

1. `你好，我刚接手一个温州蜜柑果实品质课题，准备写开题和安排试验，目前只有个大概方向。你先用几句话告诉我，能从哪些环节帮我？`
2. `我想研究氮素供应和采后温度对果实转色、可溶性固形物的影响。按这个课题，我可以先让你帮我准备什么？哪些事情需要我再提供论文或原始记录？`
3. **附上 CSV，但不要求审查：** `这是一份合作组发来的记录表，我先放在这里，稍后再看。现在先不打开、不统计，也不要审查数据；请继续帮我想想开题时该如何描述研究目标。`
4. `回到刚才的课题，我主要想研究哪两个因素和哪些果实指标？`

## 测试者观察

- 第 1、2 题应像正常咨询一样回答，不应为了展示工具而启动检索。
- 第 3 题只上传文件不应自动触发表格概览或数据审查；应先回答用户当前真正问的研究目标。
- 第 4 题检查对话上下文是否延续。
- 本组只测试日常对话和附件路由边界，不要求模型调用任何特定工具。
