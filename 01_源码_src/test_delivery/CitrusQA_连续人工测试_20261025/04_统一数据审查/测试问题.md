2. **上传 `果实成熟度监测_仪器导出.csv`、`田间调查_多批次记录.csv` 和 `果园调查_多工作表记录.xlsx`：** `整理三个批次的数据时，我发现一些记录看起来过于整齐，另一些组的重复数又不一样。请帮我做一次完整的数据质量复核：先告诉我文件和工作表是否读全，再找可能的重复、异常点、组间不平衡、跨指标数值关系和可疑的重复使用；每条线索给出原始位置和示例值。请把规则信号和可以证明的问题分开，并导出一份自动命名的 HTML 异常报告。`
3. **上传 `果实成熟度监测_仪器导出.csv`、`成熟阶段_多点测定记录.csv`、`合作组_复测设备读数.csv`、`单果鲜重_单位换算对照.csv`：** `这些记录来自不同同学，行顺序和表头格式不一样。我担心合并时发生过复制粘贴，也知道其中一份把克换成了千克，另有共用对照批。请把它们与主表比较：指出值得复核的跨行、跨列或跨文件关系，同时优先检查单位换算、重复测量和共享对照能否解释这些相似；不要把相似直接当成错误。`
4. `我需要把结果发给导师。请按“重复值、异常值、组别与重复、列/行关系、局部复用、跨文件关系、摘要统计、扫描覆盖”逐项给结论；每类有发现就写最重要的位置和复核办法，没有发现写“无”，未完成的检查单列说明。报告保持简洁，详细证据放在可下载报告里。`

## 附件对应的测试场景

- 第 1 题：多行表头、未知字段和测量通道映射。
- 第 2 题：基本数据质量、单表多表审查、跨工作表线索、报告导出。
- 第 3 题：行向/局部复用、行顺序改变后的跨文件关系，以及正常单位换算与共享对照。
- 第 4 题：面向用户的简明分类报告、逐项“有/无/未完成”以及覆盖范围说明。

## 测试者核对说明（不要发给模型，也不要放进附件）

- `果实成熟度监测_仪器导出.csv`：多行表头；两列固定差、固定比例、恒定和、少量差值集合、连续片段固定偏移、改变整数部分但保留小数尾、等差序列、分散重复值，以及多变量读数中的局部关系。
- `田间调查_多批次记录.csv`：缺失值、同列文本/数值混合、重复样本行、极端值、组别样本量不平衡及备注字段中的异常格式。
- `果园调查_多工作表记录.xlsx`：跨工作表重复结构、比例/归一化列、重复测量和一组正常换算示例。
- `成熟阶段_多点测定记录.csv`：条件在行、测量值在列，包含整行复用、比例行和局部片段复用。
- `合作组_复测设备读数.csv`：数值经过行重排后复用，并有跨记录小数尾线索；不能只按相同单元格位置比较。
- `单果鲜重_单位换算对照.csv`：`鲜重_g` 与 `鲜重_kg` 是正确的单位换算；共享对照批及重复记录可能有合理实验设计解释。
- 以上都是人工构造的审查线索，不代表真实错误或不端。扫描器受数据结构、最少观测数和计算预算限制，报告未触发不代表已经排除。
