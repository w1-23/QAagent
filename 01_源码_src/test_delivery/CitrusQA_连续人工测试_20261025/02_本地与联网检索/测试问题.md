# 连续对话：为柑橘无融合生殖开题找证据

新建会话，按顺序提问，不上传附件。每题都是同一个开题任务的延续。

## 对话

1. `我正在准备柑橘无融合生殖方向的开题背景，想弄清楚胚胎发生和种子形成有哪些已知遗传调控线索。请帮我找可靠的综述和原始研究，先给我几条最相关的证据，列出 DOI、年份和可访问来源；证据不足的地方请标出来。`
2. `你刚才提到 Hand 和 Koltunow 的 apomixis 论文。我准备把它写进开题，请打开你找到的出版方或期刊页面，核对标题、作者、期刊、年份和 DOI。哪些信息来自搜索摘要，哪些是你实际打开网页后确认的？`
3. `现在先把联网结果放一边，只看看我们本地柑橘文献库里有没有关于 citrus apomixis, genetic control, seed formation 的材料。即使没有命中，也请区分是没有召回，还是本地检索没有完成。`
4. `我准备写一段开题背景。把本地材料和刚才的公开网页证据放在一起，告诉我哪些结论有双方支持、哪些只来自一侧，并整理成可下载的证据表，附上来源链接。`

## 测试者观察

- 第 1 题是具体的文献问题，应主动检索公开资料，并在适用时补充柑橘本地语料候选；不要回复成能力介绍。
- 第 2 题检查能否读取来源页面，并把搜索结果摘要与网页正文区分开。
- 第 3 题虽用中文提出，但本地 BM25/Dense 实际查询必须先转成英文；“只看本地”时不能偷偷联网。
- 第 4 题检查本地候选是否作为联网证据补充，而不是只有联网失败才查本地；同时检查证据表下载。
- 网络失败、额度不足、权限错误、无搜索结果和本地零召回应使用不同状态。
