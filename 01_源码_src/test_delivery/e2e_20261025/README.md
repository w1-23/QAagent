# CitrusQA 本地端到端测试

本目录是当前版本唯一测试包，结果替换了旧版测试结果。问题通过真实 HTTP API 提交到本机 CitrusQA 服务，使用新的普通账号和新会话。账号、会话、管理员审计和下载产物写入 `runtime/` 隔离目录；不会改动本机已有账户、会话或数据。

## 运行内容

1. 普通问答，并在收到完成事件的同一时刻读取历史，核对刷新后回答与耗时徽标都已恢复。
2. 用阿里云百炼当前选定模型进行图片输入实测。
3. 上传论文但只请求元数据，确认未自动启动数据审查。
4. 明确请求本地英文混合检索，核对运行环境的真实检索状态。
5. 上传四份合成 CSV，要求完整数值审查及 Markdown/XLSX/HTML/JSON 导出。
6. 从 PDF 提取 DOI，测试 Web Search、登记元数据核验和核验表导出。
7. 单独要求 Web Search 与 Web Fetch 查看 Crossref 官方文档。
8. 要求生成安全、可编辑 SVG，并分别下载内嵌 SVG 的 HTML 与独立 SVG。
9. 直接提交损坏 XLSX，验证 API 拒绝状态。

合成附件取自旧测试集，仅复用输入文件；旧日志、结果和下载产物不会复用。密码和 API Key 不写入测试输出。捕获的网页内容若含 URL 内嵌登录信息，会在保存的日志和测试副本中清除。通过 `/api/v2/session/{id}/artifacts/{id}` 下载服务生成的文件，并保存 SHA-256。

## 运行

在此目录先运行 `python run_isolated_app.py`，服务只监听 `127.0.0.1:8011`。服务健康后，在另一 PowerShell 窗口运行 `python run_e2e.py`。服务使用当前本机模型、API 密钥和语料配置；所有会话与审查产物使用本目录下的隔离运行数据。

## 输出

- `summary.md`：逐项通过、失败或未触发状态。
- `results.json`：各请求的答案、工具名、耗时和实时/刷新后字段对照。
- `session_messages.json`：新会话历史接口返回结果。
- `safe_sse_log.jsonl`：经筛选的状态/工具/完成事件摘要，不包含隐藏推理或密钥。
- `downloads/` 和 `downloads_index.json`：经 API 实际下载的导出文件及校验信息。
- `fixtures/`：合成测试附件。
