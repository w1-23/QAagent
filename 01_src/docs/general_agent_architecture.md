## 产品主体与控制权

CitrusScholar 是完整 General Agent，领域资料 RAG、文献核验、数据审查、科研绘图是增强能力。search、browse、code、file 不依赖科研任务分类才能使用。模型选择方法、组合能力并依据观察调整；宿主执行权限、资源、取消、版本及真实性边界。插件只能对自己的能力和质量承诺负责，不能关闭无关通用工具或结束整个任务。

Coding 可以用于探索输入、提取、整理、转换、连接工具、诊断、修复和交付，不必先让专用工具失败；直接能完成的任务不强制写代码。插件是职责定位，现有技能、工具与渲染器无需强行改成相同技术形式。

## 生命周期

| 身份 | 含义 |
|---|---|
| session | 会话历史容器，可包含多个工作对象 |
| user turn | 一条真实用户输入及响应过程；内部控制、模型调用和工具结束都不新建用户轮 |
| run | 一轮中的执行/恢复实例；换run不刷新本轮授权或预算 |
| model attempt | 一次实际供应商请求，重试单独计账 |
| operation | 一次逻辑工具操作，映射供应商call ID，贯穿执行、取消和对账 |
| work item | 可跨轮接续的目标及版本化资产；简单问答无需建立项目 |

使用显式身份而非最后一个HumanMessage判断轮次。内部控制是宿主事件，不是用户指令。保留用户原请求；模型工作计划可修订，但不能取代授权或取消用户要求。

## 通用循环

模型提出动作 → 校验权限/参数/资源 → 保存操作意图 → 执行 → 保存观察和资产 → 模型继续。可以直接回答，也可以请求确实缺失的用户决定。合法探索与工具失败都是观察，不受“两批无科研覆盖”或“只能两次修复”终止。

停止条件为用户取消、真实资源边界、明确不能继续的状态或模型提出且经事实核验的结束。进度/停滞是诊断，不能作为伪造成功的依据。宿主只验证可验证声明和必要质量要求，不规定唯一工具序列。失败项返回同一循环，不能无工具终答后再拼接另一份交付更正。

2026-11-16 执行修订：普通有效终答在当前模型步即可交付，不强制再次调用主模型核对或重写大 JSON。宿主从实际执行回执绑定内部完成证明，校验身份、用户要求版本、操作快照和交付链接；领域科学核对由已加载 Skill 和实际工具完成，不新增独立模型。内部兼容字段 `reviewed_completion` 不再表示额外模型审核，也不构成科学正确性认证。

内部证明保存在加密图检查点；旧 pending-review 检查点继续读取原 CompletionEnvelope。公开历史保存最终答复，公开终态与历史重放均移除 completion 内部声明。任务接受结果与原始 `execution_status` 分开：辅助 partial 只有通过严格 receipt、只读核对及真实替代证据才可不阻断任务接受，原状态与统计保留。纯参数/方法准入拒绝须由宿主证明零派发或验证私有 preflight 回执，再关联后续成功操作；加载失败仅对代码声明的只读能力适用替代。用户更新后零派发的旧提案由身份及版本绑定的 superseded_proposal_ids 标识，不成为新目标。真实派发后自行返回 preparation_required 不能获得豁免。unknown、必需覆盖或资产校验问题保持未完成；可交付已知部分并标明执行限制，不为修订内部格式强迫补查。host、API、任务与历史共用同一完成规则；模型遗漏自然语言要求的语义风险仍需实际试用验证。

修复尝试与当前结果分开：宿主从同一逻辑操作/绘图修复身份，或已经校验的零派发修正与只读替代证明，发布 `tool_resolution`；终态 `tool_resolutions` 提供同样的补全信息。时间线更新旧行的解决状态，原始 status、参数、结果和错误保持不变。请求用户输入成功后即暂停的路径也即时归约纯准入拒绝，不等待终答。未知/取消的操作不因同名工具后来成功而消失。图件的任务身份包含作用域、输入快照、参数、输出槽/来源及环境和 QA 标准；主脚本、独立 renderer 和 caption 的源码/文字修订不创建新的输出义务，真实输出、尺寸或质量标准改变仍保持独立。完整执行选项继续绑定请求幂等校验。

事实事件与资产字节分别有唯一来源。快照、界面、验收视图均为投影。操作先记录意图；未知写入先查状态，不盲重放。持久租约和fencing隔离旧执行者，CAS保护对象版本。取消后迟到结果仍对账，不假定撤销已完成副作用，也不承诺通用exactly-once。

基线循环参考固定版本 pi-mono 与 OpenCode 的实际实现，来源、MIT 归属和适配差异见 [Agent loop 上游参考与适配记录](agent_loop_sources.md)。迁移目标是在 Python/FastAPI 及现有供应商适配之上，采用 Deep Agents/LangChain 公开运行器与 middleware/backend、LangGraph 持久 checkpointer；保留账号、operation、工具全文与资产服务。先验证公开扩展、协议和持久恢复，再接入生产；不维护双重生产循环，不以大规模私有patch替代成熟组件。上游的默认子代理、摘要失败策略和执行权限不能直接继承。

当前 `src/agent` 已提供以下独立模块：

- `harness.py`：生产使用公开 `create_agent`/`AgentMiddleware`，由 LangGraph 执行真实 model/tools 节点转换并同步提交检查点；保留同循环终答校验、截止时间、取消、批次调度和原生调用配对。`runtime.py` 仅保留共享值类型及基线参考测试，生产 host 不再实例化旧循环。
- `checkpoint_store.py`：身份/provider/model绑定的加密 SQLite saver，显式保留私有协议字段；公开 metadata 不放消息正文。`batch_journal.py` 在现有 jobs 库登记整批意图与已发布结果；已完成回读，不确定批次拒绝重放。
- `context_projection.py` / `context_tools.py`：受控发送视图、成熟摘要 middleware 和授权原文分页回读；原始图消息不被摘要替换。
- `events.py`：不含私有正文的进度事件；另有受保护消息检查点。检查点回调先于对应事件和下一次调度，不可将其直接当公开日志。
- `capabilities.py`：宿主安装的能力目录、schema 可发现、按需加载、插件失效隔离与执行模式元数据。
- `execution.py`：只读有界并行、写操作顺序执行、interaction 屏障、调度前重查权限、观察发布后才继续；未知写入暂停后续动作。只通过宿主注入的 operation runner 执行，不提供直接调用工具函数的后备路径。
- `model.py`：沿用计账后的 SDK 传输，保留同轮私有供应商协议状态。

生产图源码的 supervisor 已接入 `host.py`，通过 `host_tools.py` 绑定真实 job/账号/会话/请求、持久操作记录、完整结果保存和资产校验。`preset_catalog.py` 提供固定 schema 与按需加载；`host_policy.py` 依据就绪状态和明确来源限制公布能力。实际图到 session_save 的离线测试使用临时数据库，模型/工具为合成夹具；另以当前后台供应商运行真实 ModelDriver/HostTools 链路并验证完整结果与历史保存。恢复路由已通过真实 FastAPI ASGI/SSE 生命周期测试；这不等于现有部署实例已切换。

## 上下文与持续工作

当前输入包含稳定规则、授权边界、真实本轮请求、作用域正确的约束、相关工作/资产目录、轮前历史投影、本轮动作观察及按需技能。历史query不能无限累积成永久constraints。

历史消息、操作、文件、脚本、数据、核验和图件须可按授权搜索/列举，再按真实ID/版本/hash精确回读。保留原文与数值，摘要仅导航。固定恢复所需的传递依赖；临时缓存、工作资产、正式用户资料各有生命周期，缺失或过期明确可见。

四类状态分别存储和验收：会话历史是原始用户/公开动作记录；活动模型上下文是发送视图；task/run checkpoint是可执行状态；资产/证据是owner、ID、版本、hash和来源链。历史导航摘要不能冒充执行恢复，文件存在也不代表当前模型已读取。

P3 已在生产源码接入受控的同轮发送视图压缩：`WorkingContextProjection` 先加密归档原始消息并以新连接确认可读，再调用公开 `SummarizationMiddleware`。真实用户/系统消息、必需方法及受保护供应商协议组保持完整；摘要以可信内部 `SystemMessage` 进入发送视图，原始图消息不改写。`read_context_evidence` 按本轮身份精确分页回读公开原文，摘要本身不作为科学证据。摘要的实际请求计入原任务预算和截止时间；同一运行中相同前缀复用缓存，重启后重建摘要仍重新计账。原文存储、身份或协议保护失败时暂停；历史加载器写入的本机 UI 耗时 `citrus_generation_ms` 是已知元数据，不将整份历史答复误标为私有协议；未知 provider 字段仍保护。消息数保留是软偏好，按完整工具组与 token 目标选择可压缩范围。软阈值触发但没有安全缩减空间或摘要反增时，记录 deferred 并保留原始或更优缓存发送视图，仍由 ModelDriver 的真实窗口/累计预算/期限准入，不把软压缩失败当成任务失败，也不发布压缩成功文案。摘要失败不能作为普通摘要文本接受。可用 `context_compression=false` 显式关闭本轮压缩。事件只公开前后估算与回读引用，不发布私有正文。源码与实际供应商小型探针已验证，现有服务尚未切换。

单次窗口、输出预留和累计预算分开；配置128000输入/1000000累计不证明供应商窗口或实际管理员配置。采用provider能力与安全有效配置准入，不靠换run或伪造用户轮越过边界。

轮后导航使用水位和CAS，不依赖所有旧工具永远完整。取消展示记录不伪造模型tool calls。旧记录缺失不得永久阻断后续轮次；原文可回读不等于完整执行可恢复。私有供应商协议状态不得进入公开轨迹、摘要或普通日志。

## 能力与质量

- 通用工作区持久保存文件；短生命周期执行进程可重建。授权输入只读，work可编辑，输出按版本登记。目录和代码不能接触宿主路径、秘密或Docker控制socket。
- file提供目录/搜索/读写/编辑/版本；code提供执行、退出状态、stdout/stderr、结果读取及再修改。只有科研Python接口不算完整coding。
- search和browse提供公开信息发现、内容读取、链接跟随和允许的下载；领域检索是可接入来源。
- 科研问答使用网页摘要和按需读取的本地候选，摘要足够即可结束；不强制全文、登记库或额外终答审核。其他任务不强制RAG。正向要求web不等于禁止local，明确排他约束才收窄。
- CJK查询英译失败关闭仍在检索适配器执行，不禁止无关通用动作。未读候选正文只驻请求内存；明确读取的片段作为工具证据保存。
- 专业能力懒加载并隔离失败。Nature不因绘图工具可见就全局注入，Word方法不能全局禁止Python。
- 文献核验保存逐条/逐批结果，含部分完成与不确定；DOI不是唯一证据。默认回答给结论和链接；文件由用户要求触发，从保存结果经通用能力生成，不重查或重抄。核验回执的 `continuation` 在终态、可选重试或预算交付边界建议依据已存结果答复；仍保留真实 pending/retryable、字段、来源错误与原始审查状态。方法同时约束换通用 search/browse 重查已覆盖 DOI/题名/期刊的扩张，不封禁通用工具；明确的额外独立来源请求或会改变结论的具体缺口仍允许有目的补证。
- 初始科研图必须使用固定nature-figure 2.8.0（commit 7bff1d0539c0dfad6c30178bb93ce6dd8a5cebf8）的美学与实际审核。凭证绑定用途、来源、规则和产物版本/hash，与工具名无关。generic文件不能冒充合格科研图，普通截图不自动接受科研审核。
- 后续用户改图自由；保留来源、版本和真实下载，不能用初版审核背书新字节。即时草稿与权威保存分开，成图网格进入真实可编辑对象。

## Skill入口与加载证据（P4 已接线）

复用 Deep Agents 0.7.38 的公开 SkillsMiddleware 目录，`load_skill` 提交完整方法及依赖，`read_skill` 支持精确分页。加载回执绑定真实身份、包版本/hash、资源范围及实际消息字节，完整交付后才允许专用能力；压缩和恢复时复核发送视图。全量加载上限 240000 编码字符，超限明确失败，可按页读取；不静默裁掉方法。请求级 SkillSession 由 ContextVar 绑定，工具全局注册不持有会话闭包。

`GET /api/v2/skills` 认证后仅返回四个用户场景的已验证元数据：科研检索、文献核验、数据审查、科研绘图。“＋”最多选择这四项。聊天请求 `selected_skills` 保留最多 8 项精确 `{id,version,sha256}` 的旧请求兼容边界；内部目录仍有 Nature、统计、文档交付和图件编辑等可组合方法，目录条目不等于独立用户场景。图片编辑属于工作台，自然语言编辑也走同一项目保存。新请求在配额准入前检查版本/可用性，host 对实际附件和权限再次检查，再加载根方法及依赖。原始 query 不拼接 Skill 名称；选择随请求、恢复及用户问题续接保存。目录暂不可用时仍可不选技能直接提问。

`workspace_list/glob/search/read/write/edit` 已复用公开 StoreBackend。字节保存在既有 session_files，额外版本索引与 pin 在同库原子发布；写入采用版本+hash CAS，已知冲突返回 not_run 并允许同循环纠正，未知副作用仍暂停。`/input/<file_id>/<filename>` 只读、`/workspace/...` 可写；当前仅支持受限 UTF-8 文本路径/后缀、64 KiB/文件、1 MiB/视图、128 文件及每路径 128 版本，旧版本保留。文件工具不执行代码、不公开下载文件；通用 execute 仍阻塞。真实供应商已完成跨轮写入、读回和修改，不代表执行或科学计算通过。

自然语言为主入口。主Agent看到名称、短描述和可信资源入口后，自主读取相关方法；不增加独立LLM分类器，不每轮注入所有方法。可组合多个Skill。“＋”提供可选显式选择并实际加载所选方法；斜杠快捷方式后置，不影响当前验收。
