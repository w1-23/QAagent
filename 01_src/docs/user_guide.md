# CitrusSchalor 用户指南

界面内的指南分为六章，在当前页面打开；绘图创建、选对象、文字、系列与保存都归入同一章。以下按相同研究任务组织。

## 研究任务

直接说明研究目标、材料和交付要求，无需工具名或 JSON。例如：“比较两个处理的独立植株响应，说明缺失和排除，画出原始点与区间，生成可编辑 Word。”请说明独立实验单位、配对或重复测量关系；无法确定这些信息时，统计步骤会要求补充条件。

执行卡区分排队、运行、等待批准、停止请求中和真实终态。点击停止后要等待服务器确认。网络断开后可恢复已有事件和终态；恢复计算仅适用于服务器明确列出的安全步骤，不会自动重做未知副作用。执行中的补充要求以任务版本登记，在下一个安全步骤边界应用。审批有“批准”和“拒绝”，拒绝不靠超时表示。

## 资料与来源

上传或从账号资料库选择材料，再说明用途。文件、分析结果、图件和复核记录按账号隔离，不自动加入共享检索语料。模型及联网服务仅按当前请求和授权处理材料；请勿提交不适合发送给所配置服务的信息。

使用中的文件可能由任务、分析快照、Word 版本、图件或复核记录引用。存在引用时不能直接删除；先处理对应成果。图件使用固定输入快照，后续修改原文件不会悄悄改变已保存图件。资料库默认保留期限与依赖保护共同生效；账号容量达到限制时会明确拒绝新增。

文献登记身份核验不证明论文结论成立。来源不足、全文不可用、未检查或覆盖不完整会分别说明。

## 数据、统计与审查

先确认工作表、表头、响应指标、单位和实验设计。原始行身份、源文件摘要、排除和参数保存在不可变数据/分析快照中。重新分析同一快照会产生新的分析结果；计算保持全精度，显示格式单独处理。

支持的统计方法按实际设计验证。独立两组默认使用 Welch；配对、回归、因子交互、区组、重复测量、混合模型、功效和随机化具有各自输入要求。假设诊断不等于证明正态或方差相等；常量、非有限值、重复配对键和不完整设计不会静默得出结论。

审查可产生标注副本与证据复核入口。每条证据包含规则、哈希、位置、计算依据、适用条件、反例和覆盖范围。图像相似候选、数值复用或汇总差异都需要研究背景核对，不是对作者动机的判断。打开复核页可并排查看源区域、留下说明并更新状态；并发修改冲突需刷新。未执行的检查会明确列出。

## 绘图与编辑

在聊天中说明变量、研究目的和期望风格。主路径为隔离执行的 Matplotlib 脚本和适配的 nature-figure 工作流；Seaborn 复用 Matplotlib 对象模型。安全 runner 不可用时脚本路径关闭。声明式路径保留，支持有稳定身份的多子图与共享图例。

从图件卡打开工作台。左侧按文字、数据系列、图例和坐标轴组织对象；单点、单柱与刻度位于相应子组。可修改对象实际支持的文字内容、字体、字号、字重、斜体、对齐、位置、系列颜色、线型、标记、点大小、填充、描边和透明度。图例与可验证关联的系列同步。共享图例关联多条系列时需要一致编辑；无法确认链接的任意脚本图例会限制系列联动。

每次编辑先形成未保存预览；服务端重绘后才成为可导出的正式结果。支持撤销/重做，组编辑作为一个动作。保留当前预览和最近一次正式保存，刷新后恢复正式保存。两个标签页同时保存会出现版本冲突提示。

SVG、PNG、PDF 来自同一图状态，预览 SVG 与该版本下载 SVG 使用相同字节。投稿 profile 的回执检查实际尺寸、字体/线宽等已支持项目，并列出未检查项；不代表期刊认证。导出包保留源脚本或 spec、输入摘要、编辑差异和环境信息。修改数据、方法或源脚本应创建明确的新来源版本。

## 成果与续写

Excel、Word 和图件可引用同一分析结果，程序直接读取全精度数值。Word 支持结构化章节、表格、图注与参考文献的增量续写和正式 DOCX 发布；不提供在线 Word 排版编辑器。已保存草稿可以继续工作，已发布文件保持不可变身份。

只有实际登记和校验成功的文件才显示下载入口。计算完成但导出失败会分别说明，不把一次工具调用成功等同于所有要求都已交付。复杂 Excel 追加不承诺任意样式完整保真。图件 PDF 与完整报告 PDF 是不同能力，失败不会冒充已导出。

## 账号与偏好

三套既有主题和背景保持不变。账户菜单可再次打开指南、设置语言/长度/引用等偏好或更换头像。聊天不会自动写入长期科研笔记；需明确要求保存。

退出会清除页面内私有对话、待发附件和旧流；切换账号后旧响应不能覆盖新页面。账号删除先阻止新任务并排空在途工作，再释放各类成果引用、清理数据和身份。清理失败会保留可重试状态。
