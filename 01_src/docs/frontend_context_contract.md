# 上下文面板事件合同

上下文概览复用持久任务事件与 `CitrusTaskState.createContext`，实时、重放和历史恢复使用同一投影。它显示请求估算和对应尝试的供应商实测，二者不能相互替代。

## 身份和顺序

- `context_snapshot` 包含 `snapshot_version`、`logical_call_id`、`attempt_id`、请求估算、状态及可选实测。未准入快照的 `attempt_id` 为空，不接受实测拼接。
- `context_usage` 只有在 `scope=single_call` 且逻辑调用、尝试身份都匹配时，才更新相应记录。响应到达顺序不能选择面板当前调用。
- 当前快照按持久事件 `seq` 选择。`epoch` 表示上下文阶段，`source/parent_purpose` 表示用途，都不是调用身份或事件游标。
- 实时和历史 store 绑定所属 `session_id/request_id`。异请求或异会话上下文在进入缓存前拒绝，避免后续合法事件把它重新显示出来。账号和轮次生命周期的现有隔离继续生效。
- 恢复的较新快照或用量不能被较早的重放用量覆盖；后续更大 `seq` 的合法观察仍可更新。

## 显示口径

- `estimated_input_tokens`（兼容别名 `estimated_tokens`）是输入估算；六类分量为消息、系统提示、调用参数、工具定义、图片预留和协议开销。
- 只有明确的 `model_window` 才可作占比和窗口余量的分母。`input_limit`、旧 `max_tokens` 和运行配置中的工作预算均不能补成模型规格。当前生产调用未提供窗口时显示“模型窗口未知”。
- `input_limit`、整理参考阈值/目标、`output_tokens` 输出预留属于工作预算，另列且仅显示该完整请求实际提供的项。
- `provider_usage` 是此调用尝试的实测。输入/输出、缓存各项只显示已报告的有效数值；真实 0 保留，缺失、空白、布尔值、数组/对象、负数及非有限值不转成 0。不推算缓存命中率。
- 缺少调用身份的 `context_status/context_budget` 降级为历史估算；不借用任意调用实测，也不声称知道完整剩余空间。
- 新快照不继承另一调用的分量、预算、窗口或缓存。分类合计超过总量时只显示总量并说明不一致；超窗口保留真实百分比，仅对进度条几何作限幅。

## 离线验证

`web/tests/chat-turn-ui.test.cjs` 保留七组上下文断言，并以当前持久快照合同构造合成事件。覆盖估算/实测分离、调用与尝试匹配、窗口与工作预算、六类可加分量、历史不完整性、更新清空及旧事件保护、无效/不一致计数。

新增 `web/tests/context-state.test.cjs` 覆盖恢复后重放、用量乱序、嵌套终态/恢复/clear 的身份边界、按 seq 选择、未准入尝试以及新调用的字段隔离。聊天回归另覆盖异请求缓存污染和无效缓存计数。
