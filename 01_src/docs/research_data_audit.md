# CitrusScholar 数据审查

## 入口和处理范围

只有用户明确要求检查表格、源数据或统计异常时，General Agent 才会调用 `inspect_uploaded_table` 与 `audit_uploaded_data`。表格被上传或加入对话本身不会启动审查。

审查入口读取本轮上传的 CSV、TSV、XLSX、XLSM、XLS 或 XLSB 表格。系统按工作表解析，支持多个工作表；单次扫描受到行、列和总单元格上限约束。XLS/XLSB 需要 `python-calamine`。不支持读取或扫描失败的工作表会作为未完成项报告，不会被当作“没有异常”。审查使用上传字节的临时副本，不写回原文件。

数据审查的实现分为三部分：`src/research/tools.py` 负责附件选择、表格解析、确定性检查和产物登记；`src/research/data_audit_rules.py` 维护规则适用范围、触发条件、样本要求、定位方式和误报风险；`src/core/data_audit_xlsx.py` 负责在工作簿副本上标注并生成审查清单、概览和规则说明。

## 规则和发现

当前规则包括缺失、数值/文本混杂、重复行、重复主键、常量字段、用户指定范围与列关系检查、探索性 IQR 离群、表格结构提示、分组样本量与重复数检查，以及明确条件下的整数均值/标准差一致性提示。部分规则需要用户提供列映射、上下限、关系或统计口径；不适用的规则不会被默认推断。

每项规则在结果中说明适用数据、触发条件、最低样本要求、定位方式和可能误报。IQR 离群、重复、组间不平衡或整数统计信号均仅是复核线索；真实生物差异、重复测量、单位换算、舍入、加权统计和实验设计都可能形成相同信号。系统不判断数据造假、作者意图或研究有效性。

## 产物

默认产物为 `*_数据审查.xlsx`，包括：

- 复制的原始工作表；命中单元格以浅红色标记并附带 Excel 批注。
- `问题清单`：工作表、单元格、原值、规则、级别、说明和复核建议。
- `审查概览`：工作表覆盖、行列数、问题分布、限制与原始文件 SHA-256。
- `审查规则`：本版本规则的适用范围、触发条件、样本要求、定位方法和误报风险。

原附件保持不变。系统对生成工作簿执行格式/内容校验后才登记为会话成果；下载仍受会话所有权约束。用户应将标记与实验方案、原始记录、单位、公式和数据字典共同核对。

## PaperConan 来源说明

当前默认数据审查**不调用 PaperConan，也不生成 HTML 异常报告**。历史代码中的 PaperConan 请求适配器没有被活动工具注册表调用，已从服务实现移除。现行部分数值提示参考了公开的数值审查方法；来源与借鉴范围见 [`src/research/PAPERCONAN_ATTRIBUTION.md`](../src/research/PAPERCONAN_ATTRIBUTION.md)。
