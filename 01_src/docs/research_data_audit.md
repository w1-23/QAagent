# CitrusScholar 数据审查

## 入口和处理范围

只有用户明确要求检查表格、源数据或统计异常时，General Agent 才会调用 `inspect_uploaded_table` 与 `audit_uploaded_data`。表格被上传或加入对话本身不会启动审查。

审查入口读取本轮上传的 CSV、TSV、XLSX、XLSM、XLS、XLSB，以及可提取表格的 PDF 和 DOCX。系统按工作表或表对象解析；单次扫描受到行、列、单元格、工作表和发现数量上限约束。XLS/XLSB 需要 `python-calamine`。用户指定工作表时采用严格匹配：工作表不存在即失败；PDF/Word 提取出多个表格而未指定目标时也会停止，不会静默选择第一张表。不支持读取或扫描失败的对象会作为未完成项报告，不会被当作“没有异常”。审查使用上传字节的临时副本，不写回原文件。

数据审查的实现分为三部分：`src/research/tools.py` 负责附件选择、表格解析、确定性检查和产物登记；`src/research/data_audit_rules.py` 维护规则适用范围、触发条件、样本要求、定位方式和误报风险；`src/core/data_audit_xlsx.py` 负责在工作簿副本上标注并生成审查清单、概览和规则说明。

## 规则和发现

当前规则包括缺失、数值/文本混杂、重复行、重复主键、常量字段、用户指定范围与列关系检查、探索性 IQR 离群、表格结构提示、分组样本量与重复数检查，以及明确条件下的整数均值/标准差一致性提示。部分规则需要用户提供列映射、上下限、关系、主键或统计口径；不适用的规则不会被默认推断。

规则清单分别记录 `available`（工具支持）、`executed`（本次实际执行）和 `skipped`（因配置或数据前提不足未执行）及跳过原因。审查不是“规则全集都已运行”。多层表头、重复列名和空列名会保留 pandas 的实际列序号；问题单元格优先按稳定列索引定位，不靠问题文字反查。

每项规则在结果中说明适用数据、触发条件、最低样本要求、定位方式和可能误报。IQR 离群、重复、组间不平衡或整数统计信号均仅是复核线索；真实生物差异、重复测量、单位换算、舍入、加权统计和实验设计都可能形成相同信号。系统不判断数据造假、作者意图或研究有效性。

## 产物

默认产物为 `*_数据审查.xlsx`，包括：

- 复制的原始工作表；命中单元格以浅红色标记并附带 Excel 批注。
- `问题清单`：工作表、单元格、原值、规则、级别、说明和复核建议。
- `审查概览`：工作表覆盖、行列数、问题分布、限制与原始文件 SHA-256。
- `审查规则`：本版本规则的执行状态、未执行原因、适用范围、触发条件、样本要求、定位方法和误报风险。

原附件保持不变。结果文件还会登记产物 SHA-256、来源附件标识、来源 SHA-256、逻辑产物 ID、版本号和前序版本。相同来源、参数和输出可复用；来源或输出变化会创建新版本，历史链接仍指向原字节。系统对生成工作簿执行格式/内容校验、磁盘存在性、会话所有权和 SHA-256 校验后才把它计为已验证成果；下载仍受会话所有权约束。覆盖预算不足时工具返回 `partial`，并在 Excel 概览中写明截断或未扫描范围。用户应将标记与实验方案、原始记录、单位、公式和数据字典共同核对。

## PaperConan 来源说明

当前默认数据审查**不调用 PaperConan，也不生成 HTML 异常报告**。历史代码中的 PaperConan 请求适配器没有被活动工具注册表调用，已从服务实现移除。现行部分数值提示参考了公开的数值审查方法；来源与借鉴范围见 [`src/research/PAPERCONAN_ATTRIBUTION.md`](../src/research/PAPERCONAN_ATTRIBUTION.md)。
