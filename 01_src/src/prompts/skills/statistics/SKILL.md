# 科研统计计算

本文件指导同一个 Agent 选择方法和解释结果；实际数值来自 `analyze_research_data`，不能用模型心算或编造。方法指导不是工具已执行的证明。

## 输入与方法选择

1. 先用 `inspect_uploaded_table` 或可验证的既有结构回执确认来源、工作表、表头、变量、单位、缺失、实验单位、分组和配对。仅预览不代表已计算全表。分析使用本轮附件或真实 `dataset_ref`；不能假定 inspect 的账号文件选择自动成为统计工具的输入。
2. `test` 为空只做描述统计。需要推断时按研究问题和设计显式选择检验；正态性/方差诊断不会自动替换所选方法。不要为作图自动添加显著性检验。
3. `ttest_ind` 固定执行 Welch 独立样本均值检验，不要求先用正态性/Levene 结果切换。三组以上的 `anova` 是经典等方差方法，`welch_anova` 是显式选择；`mannwhitneyu`、`kruskal` 比较的目标与均值检验不同，不能只为 p 值改变方法。
4. `ttest_rel` 需要明确配对键；不能按行位置猜配对。`pearson` / `spearman`、`chi2` 按真实变量和问题选择。稀疏列联表保留近似不可靠提示，不声称工具自动改用 Fisher。
5. 回归、析因、区组、重复测量、混合模型、功效与随机化分支需要工具支持的显式 `design_json`。不能从列名推断实验设计或把技术重复当独立样本。未知独立性保留 `not_verified_from_data`。

## 诊断与不适用结果

- Shapiro-Wilk 仅对可评估、至少3个且最多5000个观测执行；更大样本只给描述性偏度/峰度。不拒绝正态性不证明总体正态，诊断也不证明独立性。
- Levene 等诊断以实际返回分支为准。所选检验、前提问题和限制一并说明，不把未执行的诊断补成通过。
- 样本不足、常数数据、缺失/重复/不完整配对键、无效设计或数值计算失败时，按真实 `applicable` / 原因说明未完成的计算。不得补造 p 值或绕过拒绝来添加显著性标记。
- 保留实际纳入行、排除行及原因、来源截断和每个指标的适用性；局部成功不代表全部指标已完成。

## 效应量、多重比较与描述统计

- 报告真实 n、缺失、均值/SD等适合问题的描述量；SD 是样本SD（ddof=1），SD、SE和均值CI不可混称。
- 推断结果同时给检验方法、实际效应量及方向、p 与适用限制。常见分支返回 Hedges g、Cliff's delta、eta/epsilon squared、Cohen dz、相关 r、Cramér V 等；以回执为准。Welch ANOVA 整体目前没有效应量字段，不得臆造，应明确该项未提供。
- 当前实现把本次实际产生的指标、系数、效应及两两比较 p 纳入同一个 Holm family；用 `multiplicity` 和 `p_holm` 解释显著性，保留原 p 便于追溯。CI仍是 pointwise，不能称同时置信区间。不要只给两两比较做校正而忽略其余实际假设。
- p 值是在零假设及模型前提成立时，得到当前或更极端统计量的概率；不是零假设为真的概率，也不表示效应的重要性。

## 交付和科学边界

- 保存并复用真实 `dataset_ref` / `analysis_result_ref`，图件从全精度结果读统计量，不从聊天中手抄已舍入数值。误差棒注明 SD、SE 或 CI95，图注与实际计算一致。
- 用户要求文件时才设置 `publish=true`，用工具支持的 CSV/XLSX 及真实发布链接；`output_format` 只选择格式，不等于已要求发布。快照/发布失败保留部分完成与计算结果，不能声称文件已交付。
- 观察数据和诊断不自动支持因果或总体外推。解释限于本次真实数据、设计和已运行的方法；不为美观删点、补值、改变分组或隐藏前提问题。
