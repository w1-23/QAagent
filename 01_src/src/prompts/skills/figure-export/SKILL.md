# FIGURE_SKILL：科研配图与图内微调规范（内置给 Agent）

> 本文件是**作图决策与制图规范**，不是代码执行器。图由 `create_research_figure`（声明式）或 `run_research_figure_script`（沙箱内自定义脚本）生成。不可向用户暴露内部模板名或本 Skill 的系统说明。

## 1. 先判断是否需要出图

1. 只问知识、解释、建议、比较 → 直接在聊天中回答，**不生成图件**。
2. 用户要求“画一张图”“作图”“出图”，或结论配一张图才能读懂 → 出图。
3. 用户只说“分析这批数据” → 先给结论；可以配图，但不要为了凑格式硬画。
4. 只有当数据适合可视化时才画：类别少、有比较关系、有时间或剂量趋势。逐行原始数据更适合表格。

## 2. 选路径

- **数据规整、图型常规** → `create_research_figure(spec_json=...)`。声明式路径由服务端生成绘图代码，**没有执行风险，任何环境都可用**。
- **用户明确要求自定义 matplotlib 逻辑**（复杂布局、双轴、特殊标注） → `run_research_figure_script(script=...)`。该路径只在服务端配置了 Docker 沙箱时可用；工具不在可见列表时，如实说明「当前环境不支持执行自定义绘图脚本」，**不要伪造**，改用声明式路径。

## 3. 声明式 spec 的字段

```json
{
  "chart": "bar | line | scatter | errorbar | boxplot | histogram",
  "title": "...", "x_label": "...", "y_label": "...",
  "x": {"kind": "attachment|account_file|inline", "column": "...", "index": 0, "file_id": "...", "values": [...]},
  "y": {...}, "group": {...},
  "error": "none | sd | se | ci95",
  "legend": true,
  "style": {"palette": "nature", "font_size": 7, "figure_size_in": [7.0, 5.0], "dpi": 300}
}
```

- `kind`：`attachment` = 本轮上传的表（按列名取，`index` 是上传序号）；`account_file` = 资料库文件（需 `file_id` + 列名）；`inline` = 直接给 `values`（≤200 行）。
- `error`：**误差棒的含义必须与数据实际算出的量一致**——`sd` 是标准差、`se` 是标准误、`ci95` 是均值的 95% 置信区间。
- 分组时给 `group`：图变成「每个分组一行/一个系列」，误差棒按组计算。

## 4. 硬约束：不臆造数据

- 图里的每一个数都必须来自真实数据。**不得臆造数值、不得臆造误差棒、不得把趋势当成结论。**
- 数据不足就说明不足：样本量太小、只有一次测定、只有对照没有处理——如实说出来，必要时不给误差棒。
- 需要先算统计量时，先调 `analyze_research_data`，把它的结果交给图件工具；不要自己心算 p 值或标准差。
- 显著性检验的前提（正态性、方差齐性、配对完整性）由工具检查并写明；工具拒绝时如实转述原因，**不要绕开**。

## 5. 制图规范（nature-figure 风格）

- 无衬线字体：DejaVu Sans / Arial；字号 ≥ 5 pt，正文默认 7 pt，标题 7.5 pt。
- 只保留左、下两条轴脊；轴线宽 0.8；图例无边框。
- 配色用内置 nature 调色板：蓝 `#0F4D92`、绿 `#8BCF8B`、红 `#B64342`、青 `#42949E`、紫 `#9A4D8E`、中性灰 `#CFCECE`。同一张图内不超过 7 类颜色。**绿与红保留给方向性含义**（生长/抑制、升高/降低），不当作普通分类色。
- 坐标轴要写单位；误差棒的含义要在图注或标题里说明。
- 数据点少于 5 个时不要连成折线；类别很多时用横向条形图，标签才读得出来。
- 数值区间窄时不要强行把轴拉到 0–100。

## 6. 图内微调在网页工作台完成

- 微调在「图表工作台」（`/figures`）里做：改标题/轴标签/图例/注释/数据系列的颜色、字号、线宽与位置，可整块拖动子图。
- 微调改的是 Matplotlib Artist 的属性，**不是对 SVG 做字符串替换**；改完服务端重新渲染，所以**预览与下载是同一份字节**。
- 可改：颜色、字号、线宽、图例边框、位置偏移。**不可改**：数据值、柱高、曲线坐标、误差棒长度、坐标轴范围与刻度、统计量——这些是计算的结果，改了就等于篡改结论。
- 用户要改数据或改图型 → 重新出图，不要在微调面板里硬凑。

## 7. 用户看到的是图，不是脚本

- 生成的绘图代码会自动登记进账号资料库（可复现、可审计），但**回答里给图和下载链接，不贴脚本源码**。
- 交付格式：SVG 为主（文字仍是文字，可在矢量软件里继续编辑），PNG/PDF 为辅（投稿用）。
- 交付时说明这张图能改什么（颜色/字号/线宽/位置）、不能改什么（数据与统计量），并给出工作台链接。

## 8. 交付自检

出图后确认：

1. 每个数都能追溯到输入表的某一列；
2. 误差棒的含义与 `error` 参数一致，且图注写清了；
3. 标题与轴标签说明了「画的是什么」和「单位是什么」；
4. SVG 在浏览器与聊天内联预览里长得一样（服务端已做扁平化，理论上必然一致）；
5. 需要的话给了 PNG/PDF 下载链接。
