# CitrusScholar / CitrusQA · 柑橘科研辅助智能体

CitrusScholar（源码中部分名称沿用 CitrusQA）是面向柑橘科学、农业研究与通用科研任务的 Web AI 工作台。它围绕 **提问 → 检索与阅读 → 证据核对 → 数据审查 → 图表和报告导出 → 文件管理** 组织能力，不只是聊天机器人。

> **科研边界**：模型回答需要研究者核验；病害图片分析仅用于辅助筛查，不是确诊；数据审查的异常信号不等于研究数据存在错误或学术不端。

**文档入口**：[完整用户指南](01_源码_src/docs/user_guide.md) · [数据审查说明](01_源码_src/docs/research_data_audit.md) · [Linux 部署指南](01_源码_src/docs/deploy_linux.md)

## 核心功能

| 工作任务 | 支持的能力 | 可获得的结果 |
|---|---|---|
| 科研问答与文献综述 | 主 Agent、Web Search/Web Fetch、开放论文获取、本地混合检索 | 有来源的解释、对比与研究线索 |
| 柑橘文献与品种查询 | 已部署的论文库、UCR 与中文品种库等语料 | 证据片段、来源标识、可访问的原文入口 |
| 论文及附件解读 | 图片、PDF、Word、CSV、Excel 等 | 方法、结果、局限解读，文档内问答 |
| 文献核验 | DOI、标题、作者、期刊、年份登记信息核对 | 核验结果与不一致提示 |
| 原始数据审查 | 表头识别、重复/缺失/离群/逻辑等规则 | **标注 Excel**：单元格标色、批注、问题清单和审查概览 |
| 科研设计与课题整理 | 实验设计、研究记录、整理和导出 | 结构化方案及适用格式的文件 |
| 科研图示 | 开启可视化后生成安全校验的 SVG | 预览、下载与复制 SVG 源码 |
| 文献证据导出 | 书目及证据表 | XLSX、RIS、BibTeX 等 |

普通问答不强制检索；工具是否调用取决于问题、来源限制、服务是否可用及账号权限。可明确提出“仅本地”“仅联网”“核验引用”“不要修改原数据”等要求。

## Web 界面全览

### 左侧：会话与快捷操作

左侧会话栏可切换历史、折叠展开并调整宽度。快捷按钮自上而下为 **使用指南 → 账号记忆 → 宠物 → 主题**。

- **使用指南**：打开内置的六页入门导览。
- **账号记忆**：查看该账号的偏好与长期事实；清空记忆不等于删除会话历史。账号记忆与用户明确保存的课题记录属于不同功能。
- **宠物**：小橘支持拖动、点击互动、80%–180% 缩放、隐藏/恢复、默认位置恢复；自主动作有安静/自然/活泼三档，真实任务动作优先于随机待机。
- **主题**：春日花笺、午后书房、夜林花语，可启用全局减少动画。

### 中间：聊天、执行过程与上下文

输入区支持添加附件和开启“可视化”。回答中可展开工具轨迹，查看执行、完成、失败、无结果或部分完成等状态。绿色小芽和橙色“**小橘正在回答您的问题...**”表示请求处理中，不能代替真实工具状态。

**上下文概览**使用原有的圆形入口，并非重复放在左侧快捷栏中。它反映当前会话的公开上下文状态，**不等于模型隐藏推理**；系统也不承诺每轮都会完整发送全部历史。右侧橙色轮次导航按真实用户提问建立刻度，便于跳转长会话中的不同问题，工具事件不算新的用户提问。

### 右侧：账号资料库

资料库将**上传资料**和**生成成果**分组展示。用户可以：预览文件、将文件引用到当前会话（＋）、下载原件、查看文件信息；有来源轮次的生成文件可定位到对应会话，SVG 文件支持复制源码。资料库可拖动边缘调宽，宽窗口使用紧凑多列布局，让一屏显示更多文件。

资料库当前界面说明文件保留周期为**30 天未活动**，实际以部署的服务规则为准，重要产物应及时下载备份。把附件加入会话**不代表**将其自动添加到共享科研语料。

### 本地文献原文阅读

回答中可识别的本地来源标识及本轮来源入口可以打开本地语料阅读器，提供阅读视图、原始 Markdown、复制文本与可用的 DOI 外链；**无需先通过 DOI 查找才能打开原文**。该阅读文本可能由已存的语料 chunk 按顺序还原，不保证和出版方 PDF 的排版完全一致，也不能始终精确定位检索段落。私有实验方法遵循访问权限。

## 示例：这样提出任务

> **检索研究进展：** 比较近五年柑橘黄龙病 PCR、qPCR、图像识别检测的研究证据，注明论文 DOI 和局限。

> **只看本地文献：** 仅检索本地语料，查询 RWP-RK 在柑橘中的研究，说明有证据和缺乏证据的部分，并给出可打开的本地来源。

> **审查 Excel：** 检查这份 qPCR 工作簿的必填缺失、重复行、组内异常值和处理组逻辑，生成标注 Excel，不修改原文件。

> **生成图示：** 开启可视化，绘制柑橘黄龙病检测流程 SVG，标出症状初筛、采样、PCR/qPCR 验证与结果复核，并提供原文件。

更多操作方式与示例见 [用户指南](01_源码_src/docs/user_guide.md)。

## 科研工具和来源

- **联网检索**：Web Search、Web Fetch、基于 DOI/题名获取公开论文和开放补充材料；网络失败、付费限制、未发现资料应区别说明。
- **本地检索**：使用当前部署的授权语料，可能包括本地科研文献、UCR、中文柑橘品种及实验方法；具体可用范围以当前实例为准。
- **文献核验**：利用 Crossref、DataCite 等登记元数据核对来源；登记库未查到并不等于文献不存在。
- **数据审查**：先读取表结构，按适用规则分析并生成 **`*_数据审查.xlsx`**；问题单元格浅红标注、附批注和清单。旧版“默认只输出 HTML 异常报告”不再是当前工具的默认行为。
- **科研导出**：文献证据可导出 XLSX/RIS/BibTeX，其他研究报告按工具真实支持的格式输出。
- **科研 SVG**：图示经服务端安全检查后登记为生成文件；界面可预览、下载和复制源码。

## 账号、管理与科研边界

会话、资料库和账号记忆按账号隔离；私有实验方法有额外访问限制。附件内容可能发送给配置的模型或联网服务，不适合外发的资料请不要上传。

仅管理员可使用 `/admin`。管理后台包括账号、服务与请求审计等功能，以及**文献候审库**：保存成功抓取的论文原文或用户明确授权上传的原件，供人工审阅、保留或拒绝。**候审库不会自动切块、向量化或激活正式语料。**

病害图片由支持视觉的主模型辅助分析，独立柑橘病害分类器未启用。扫描 PDF、复杂 Word/Excel、外部网页的可读性可能受格式和网络限制。异常检测属于辅助核查，不判断造假。
